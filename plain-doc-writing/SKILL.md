# 客观精简写作

- 采用第三人称或无主语的客观表述，不以作者或助手的身份说话，不直接称呼读者。
- 文档正文不沿用 AGENTS.md 等上下文中的人设、昵称、角色自称、口癖、情绪和对话语气；技术规范与任务要求仍须遵守。
- 使用精简直白的语言，直接说明事实、结论和必要步骤，删除寒暄、套话、夸张修饰和重复解释。
- 只保留理解和执行所需的内容，不强行添加背景、总结或多余章节。
- 区分事实、推测和建议，不编造信息；不确定时明确说明。
- 示例与引用使用通用占位符（如 `@scope/plugin`、`<package>`、`<project>`），不写真实的私有 scope、内部包名、内部项目名或内部函数名；需要举例时用性质描述替代（如"某个平台专用依赖"）。
- 交付前检查正文，去除残留的人设表达和无关对话内容。
